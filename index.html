🔐 Authentication

These endpoints handle user registration and login. No token needed here.

POST
Register a New User
/api/auth/register/
Creates a new user account. Onboarding begins automatically after registration.
Public›
Request Body (JSON)
{ "email": "amina@ecosort.com", "phone_number": "08011111111", "password": "1234", "user_type": "household", "full_name": "Amina Yusuf", "location": "Bariga, Lagos", "language": "pidgin", "waste_type": "plastic" }
Response
201 Created
{ "message": "Registration successful!", "userId": 1, "userType": "household" }
POST
Login with Phone Number
/api/auth/login/
Login with phone number and password. Returns a token for all protected routes.
Public›
Request Body (JSON)
{ "phone_number": "08011111111", "password": "1234" }
Response
200 OK
{ "message": "Login successful!", "token": "9944b09199c62bcf9418ad846dd0e4bbdfc6ee4b", "userId": 1, "userType": "household" }
POST
Request OTP
/api/auth/request-otp/
Generates a 4-digit OTP tied to a phone number. Expires after 10 minutes. Sent via Africa's Talking SMS in production.
Public›
Request Body (JSON)
{ "phone_number": "08011111111" }
Response
200 OK
{ "message": "OTP generated successfully!", "otp": "4521", "note": "In production this OTP will be sent via SMS" }
POST
Verify OTP
/api/auth/verify-otp/
Verifies the OTP code. If correct and not expired, returns a login token.
Public›
Request Body (JSON)
{ "phone_number": "08011111111", "otp": "4521" }
Response
200 OK
{ "message": "OTP verified! Login successful!", "token": "9944b09199c62bcf9418ad846dd0e4bbdfc6ee4b", "userId": 1, "userType": "household" }

View and update personal information. A valid token is required.

🎯 Onboarding

Every new user goes through a 5-step onboarding journey. Completing all 5 steps triggers a first reward notification.

GET
Check Onboarding Progress
/api/onboarding/status/
Shows which of the 5 steps a user has completed.
🔒 Token Required›
🔒 Header: Authorization: Token YOUR_TOKEN_HERE
Response
200 OK
{ "currentStep": 3, "step1Completed": true, "step2Completed": true, "step3Completed": false, "step4Completed": false, "step5Completed": false, "isCompleted": false, "startedAt": "2026-04-25T10:00:00Z", "completedAt": null }
POST
Complete an Onboarding Step
/api/onboarding/complete/
Called when a user finishes one of the 5 steps. Step 5 triggers a reward notification.
🔒 Token Required›
🔒 Header: Authorization: Token YOUR_TOKEN_HERE
Request Body (JSON)
{ "step": 1 }
Response
200 OK
{ "message": "Step 1 completed!", "nextStep": 2 }

🚛 Pickup & Confirmation

Households request pickups and receive a secure confirmation code. Collector confirms the code and 10 points are credited per kg.

POST
Create Pickup Request
/api/pickup/request/
Creates a pickup request and generates a cryptographic code. Expires in 4 hours, single-use.
🔒 Token Required›
🔒 Header: Authorization: Token YOUR_TOKEN_HERE
Request Body (JSON)
{ "waste_type": "plastic", "weight_kg": 5.0 }
Response
201 Created
{ "message": "Pickup request created!", "pickup_id": 1, "confirmation_code": "a3f9d2e1b4c87f2d...", "expires_at": "2026-05-13T14:00:00Z", "note": "Code expires in 4 hours" }
POST
Confirm Pickup with Code
/api/pickup/confirm/
Collector submits code and weight. 10 points credited per kg. Code is single-use, 4-hour expiry.
🔒 Token Required›
🔒 Header: Authorization: Token YOUR_TOKEN_HERE
Request Body (JSON)
{ "code": "a3f9d2e1b4c87f2d...", "weight_kg": 4.5 }
Response
200 OK
{ "message": "Pickup confirmed!", "weight_kg": 4.5, "points_credited": 45, "pickup_status": "completed" }
GET
My Pickup Requests
/api/pickup/my-pickups/
Returns all pickup requests with status and points credited.
🔒 Token Required›
🔒 Header: Authorization: Token YOUR_TOKEN_HERE
Response
200 OK
[ { "id": 1, "waste_type": "plastic", "weight_kg": 4.5, "points_credited": 45, "status": "completed", "created_at": "2026-05-13T10:00:00Z" } ]
🏪 Marketplace

Sellers list recyclable materials and buyers purchase them. Listings auto-expire after 48 hours. Accessible via app and USSD.

GET
Get All Active Listings
/api/marketplace/listings/
Returns all active listings. Filter by ?material_type=plastic. Expired listings are auto-removed.
Public›
Optional Filter
/api/marketplace/listings/?material_type=plastic
Response
200 OK
[ { "id": 1, "seller_name": "amina_yusuf", "material_type": "plastic", "quantity_kg": 10.0, "price_per_kg": 90.0, "total_price": 900.0, "location": "Bariga, Lagos", "status": "active", "expires_at": "2026-05-15T10:00:00Z", "is_expired": false } ]

📱 SMS — Africa's Talking

SMS integration powered by Africa's Talking. Used for OTP delivery, pickup confirmations and marketplace notifications. Architecture: Django Backend → Africa's Talking SDK → Telecom Network → User receives SMS.

POST
Send SMS
/test-sms/
Sends an SMS to a phone number via Africa's Talking. Used for OTP delivery and notifications. Powered by AT_USERNAME and AT_API_KEY environment variables.
Public›
📱 Powered by Africa's Talking SDK · Sandbox mode for testing · Production mode for live SMS delivery
Environment Variables Required
AT_USERNAME = sandbox AT_API_KEY = your_api_key_here
Request Body (JSON)
{ "phone_number": "+2348011111111", "message": "Your Ecosort OTP is: 4521. Expires in 10 minutes." }
Response
200 OK
{ "message": "SMS sent successfully!", "recipients": [ { "number": "+2348011111111", "status": "Success", "cost": "NGN 4" } ] }
Architecture Flow
Django Backend ↓ Africa's Talking SDK ↓ Telecom Network ↓ User receives SMS
