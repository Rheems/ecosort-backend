🔐 Authentication

These endpoints handle user registration and login. No token needed.

POST
Register a New User
/api/auth/register/
Creates a new user account. Onboarding begins automatically.
Public›
Request Body (JSON)
{ "email": "amina@ecosort.com", "phone_number": "08011111111", "password": "1234", "user_type": "household | collector | buyer | brand", "full_name": "Amina Yusuf", "location": "Bariga, Lagos", "language": "english | pidgin", "waste_type": "plastic" }
Response
201 Created
{ "message": "Registration successful!", "userId": 1, "userType": "household" }
POST
Login with Phone Number
/api/auth/login/
Login and get token for all protected routes.
Public›
Request Body (JSON)
{ "phone_number": "08011111111", "password": "1234" }
Response
200 OK
{ "message": "Login successful!", "token": "9944b09199c62bcf9418ad846dd0e4bbdfc6ee4b", "userId": 1, "userType": "household" }
POST
Request OTP
/api/auth/request-otp/
Generates a 4-digit OTP. Expires in 10 minutes. Sent via Africa's Talking SMS.
Public›
Request Body (JSON)
{ "phone_number": "08011111111" }
Response
200 OK
{ "message": "OTP generated successfully!", "otp": "4521", "note": "In production this OTP will be sent via SMS" }
POST
Verify OTP
/api/auth/verify-otp/
Verifies OTP. Returns login token if valid.
Public›
Request Body (JSON)
{ "phone_number": "08011111111", "otp": "4521" }
Response
200 OK
{ "message": "OTP verified! Login successful!", "token": "9944b09199c62bcf9418ad846dd0e4bbdfc6ee4b", "userId": 1, "userType": "household" }

🎯 Onboarding

Every new user goes through a 5-step onboarding journey. Step 5 triggers a first reward notification.

GET
Check Onboarding Progress
/api/onboarding/status/
Shows which of the 5 steps a user has completed.
🔒 Token Required›
🔒 Header: Authorization: Token YOUR_TOKEN_HERE
Response
200 OK
{ "currentStep": 3, "step1Completed": true, "step2Completed": true, "step3Completed": false, "isCompleted": false, "startedAt": "2026-04-25T10:00:00Z" }
POST
Complete an Onboarding Step
/api/onboarding/complete/
Called when a user finishes one of the 5 steps. Step 5 triggers a reward notification.
🔒 Token Required›
🔒 Header: Authorization: Token YOUR_TOKEN_HERE
Request Body (JSON)
{ "step": 1 }
Response
200 OK
{ "message": "Step 1 completed!", "nextStep": 2 }
📚 Education Engine

Six waste sorting modules. Households see all 6. Collectors see Metal, Organic and E-waste only (Collector Safety Track). Pass all modules to unlock Full Sorter or Full Collector badge.

GET
Get All Guides
/api/education/guides/
Returns guides filtered by user type. Households get 6. Collectors get 3.
Public›
Response
200 OK
[ { "id": 1, "name": "plastic", "description": "...", "sorting_guide": "...", "tips": "...", "questions": [...] }, { "id": 2, "name": "glass", ... }, { "id": 3, "name": "metal", ... }, { "id": 4, "name": "paper", ... }, { "id": 5, "name": "organic", ... }, { "id": 6, "name": "ewaste", ... } ]

🚛 Pickup & Confirmation

Households request pickups and receive a secure confirmation code. Collector confirms and 10 points are credited per kg.

POST
Create Pickup Request
/api/pickup/request/
Creates a pickup request and generates a cryptographic code. Expires in 4 hours, single-use.
🔒 Token Required›
🔒 Header: Authorization: Token YOUR_TOKEN_HERE
Request Body (JSON)
{ "waste_type": "plastic", "weight_kg": 5.0 }
Response
201 Created
{ "message": "Pickup request created!", "pickup_id": 1, "confirmation_code": "a3f9d2e1b4c87f2d...", "expires_at": "2026-06-11T14:00:00Z", "note": "Code expires in 4 hours" }
POST
Confirm Pickup with Code
/api/pickup/confirm/
Collector submits code and weight. 10 points credited per kg. Single-use, 4-hour expiry.
🔒 Token Required›
🔒 Header: Authorization: Token YOUR_TOKEN_HERE
Request Body (JSON)
{ "code": "a3f9d2e1b4c87f2d...", "weight_kg": 4.5 }
Response
200 OK
{ "message": "Pickup confirmed!", "weight_kg": 4.5, "points_credited": 45, "pickup_status": "completed" }
GET
My Pickup Requests
/api/pickup/my-pickups/

🏪 Marketplace

Sellers list recyclable materials. Buyers purchase. Listings auto-expire after 48 hours. Role-based: households/collectors create, buyers/brands purchase.

GET
Get All Active Listings
/api/marketplace/listings/
Returns all active listings. Filter by ?material_type=plastic.
Public›
Response
200 OK
[ { "id": 1, "seller_name": "amina_yusuf", "material_type": "plastic", "quantity_kg": 10.0, "price_per_kg": 300.0, "total_price": 3000.0, "location": "Bariga, Lagos", "status": "active", "expires_at": "2026-06-13T10:00:00Z", "is_expired": false } ]
POST
Create Listing
/api/marketplace/listings/create/
Create a listing. Only households and collectors. Auto-expires after 48 hours.
