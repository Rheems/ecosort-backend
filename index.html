🔐 Authentication

These endpoints handle user registration and login. No token needed here.

POST
Register a New User
/api/auth/register/
Creates a new user account. Onboarding begins automatically after registration.
Public›
Request Body (JSON)
{ "email": "amina@ecosort.com", "phone_number": "08011111111", "password": "1234", "user_type": "household", "full_name": "Amina Yusuf", "location": "Bariga, Lagos", "language": "pidgin", "waste_type": "plastic" }
Response
201 Created
{ "message": "Registration successful!", "userId": 1, "userType": "household" }
POST
Login with Phone Number
/api/auth/login/
Login with phone number and password. Returns a token for all protected routes.
Public›
Request Body (JSON)
{ "phone_number": "08011111111", "password": "1234" }
Response
200 OK
{ "message": "Login successful!", "token": "9944b09199c62bcf9418ad846dd0e4bbdfc6ee4b", "userId": 1, "userType": "household" }
POST
Request OTP
/api/auth/request-otp/
Generates a 4-digit OTP tied to a phone number. Expires after 10 minutes. In production, sent via SMS through Termii.
Public›
Request Body (JSON)
{ "phone_number": "08011111111" }
Response
200 OK
{ "message": "OTP generated successfully!", "otp": "4521", "note": "In production this OTP will be sent via SMS" }
POST
Verify OTP
/api/auth/verify-otp/
Verifies the OTP code. If correct and not expired, returns a login token — no password needed.
Public›
Request Body (JSON)
{ "phone_number": "08011111111", "otp": "4521" }
Response
200 OK
{ "message": "OTP verified! Login successful!", "token": "9944b09199c62bcf9418ad846dd0e4bbdfc6ee4b", "userId": 1, "userType": "household" }
👤 User Profile

View and update personal information. A valid token is required for all profile endpoints.

GET
Get My Profile
/api/profile/me/
Fetches the profile of the currently logged-in user — name, location, language, channel and waste type.
🔒 Token Required›
🔒 Header: Authorization: Token YOUR_TOKEN_HERE
Response
200 OK
{ "fullName": "Amina Yusuf", "location": "Bariga, Lagos", "languagePreference": "pidgin", "channel": "whatsapp", "wasteType": "plastic" }
PUT
Update My Profile
/api/profile/me/
Update profile details like location, language, waste type or preferred channel.
🔒 Token Required›
🔒 Header: Authorization: Token YOUR_TOKEN_HERE
Request Body (JSON)
{ "fullName": "Amina Yusuf", "location": "Surulere, Lagos", "languagePreference": "english", "channel": "whatsapp", "wasteType": "organic" }
Response
200 OK
{ "message": "Profile updated!" }
GET
Get My Points Balance
/api/profile/points/
Returns total points earned from confirmed waste pickups. 10 points credited per kg of waste collected.
🔒 Token Required›
🔒 Header: Authorization: Token YOUR_TOKEN_HERE
Response
200 OK
{ "user_id": 1, "total_points": 45, "message": "You have 45 points" }
🎯 Onboarding

Every new user goes through a 5-step onboarding journey. Completing all 5 steps triggers a first reward notification.

GET
Check Onboarding Progress
/api/onboarding/status/
Shows which of the 5 steps a user has completed and which are still pending.
🔒 Token Required›
🔒 Header: Authorization: Token YOUR_TOKEN_HERE
Response
200 OK
{ "currentStep": 3, "step1Completed": true, "step2Completed": true, "step3Completed": false, "step4Completed": false, "step5Completed": false, "isCompleted": false, "startedAt": "2026-04-25T10:00:00Z", "completedAt": null }
POST
Complete an Onboarding Step
/api/onboarding/complete/
Called when a user finishes one of the 5 steps. Completing step 5 triggers a reward notification automatically.
🔒 Token Required›
🔒 Header: Authorization: Token YOUR_TOKEN_HERE
Request Body (JSON)
{ "step": 1 }
Response (Steps 1–4)
200 OK
{ "message": "Step 1 completed!", "nextStep": 2 }
Response (Step 5 — Final)
200 OK
{ "message": "Onboarding complete! First reward notification queued." }
📚 Education Engine

Six waste sorting modules — plastic, glass, metal, paper, organic and e-waste. Each has a sorting guide and a 5-question quiz. Pass all 6 to unlock the "Full Sorter" master badge.

GET
Get All 6 Category Guides
/api/education/guides/
Returns all 6 waste category guides with sorting instructions, tips and quiz questions.
Public›
Response
200 OK
[ { "id": 1, "name": "plastic", "description": "Plastic waste includes bottles and containers...", "sorting_guide": "1. Rinse all bottles\n2. Flatten to save space...", "tips": "Avoid pure water sachets and styrofoam.", "questions": [...] }, { "id": 2, "name": "glass", ... }, { "id": 3, "name": "metal", ... }, { "id": 4, "name": "paper", ... }, { "id": 5, "name": "organic", ... }, { "id": 6, "name": "ewaste", ... } ]
GET
Get Single Category Guide
/api/education/guides/<category>/
Fetch the guide and quiz for one specific category. Replace <category> with: plastic, glass, metal, paper, organic or ewaste.
Public›
Example URL
/api/education/guides/plastic/
Response
200 OK
{ "id": 1, "name": "plastic", "description": "Plastic waste includes bottles and containers...", "sorting_guide": "1. Rinse all plastic bottles\n2. Flatten to save space\n3. Remove all caps", "tips": "Avoid pure water sachets, styrofoam and plastic bags.", "questions": [ { "id": 1, "question": "What should you do to plastic bottles before sorting?", "option_a": "Crush them with your feet", "option_b": "Rinse and flatten them", "option_c": "Burn them", "option_d": "Leave them as they are" } ] }
POST
Submit Quiz Answers
/api/education/quiz/submit/
Submit answers for a category quiz. Returns score, badge awarded and feedback. Gold = 100%, Silver = 60%+, Bronze = 40%+. Earn all 6 badges to unlock the Full Sorter master badge.
🔒 Token Required›
🔒 Header: Authorization: Token YOUR_TOKEN_HERE
Request Body (JSON)
{ "category_id": 1, "answers": { "1": "B", "2": "B", "3": "B", "4": "B", "5": "C" } }
Response
200 OK
{ "score": 4, "total": 5, "percentage": 80.0, "badge_awarded": "silver", "full_sorter_unlocked": false, "feedback": [ { "question": "What happens if you mix styrofoam with plastic?", "your_answer": "A", "correct_answer": "C", "hint": "Review the plastic sorting guide" } ] }
GET
My Quiz Results
/api/education/quiz/results/
Returns all quiz results for the logged-in user — scores, badges earned and completion dates.
🔒 Token Required›
🔒 Header: Authorization: Token YOUR_TOKEN_HERE
Response
200 OK

🚛 Pickup & Confirmation

Households request waste pickups and receive a secure confirmation code. When the collector confirms the code, 10 points are credited per kg of waste collected.

POST
Create Pickup Request
/api/pickup/request/
Creates a new pickup request and generates a cryptographic confirmation code. The code expires in 4 hours and can only be used once.
🔒 Token Required›
🔒 Header: Authorization: Token YOUR_TOKEN_HERE
Request Body (JSON)
{ "waste_type": "plastic", "weight_kg": 5.0 }
Response
201 Created
{ "message": "Pickup request created!", "pickup_id": 1, "confirmation_code": "a3f9d2e1b4c87f2d9e6a3b8c1d4e7f2a...", "expires_at": "2026-05-13T14:00:00Z", "note": "Code expires in 4 hours" }
POST
Confirm Pickup with Code
/api/pickup/confirm/
Collector submits the confirmation code and actual weight. System validates the code and credits 10 points per kg. Code is single-use and expires after 4 hours.
🔒 Token Required›
🔒 Header: Authorization: Token YOUR_TOKEN_HERE
Request Body (JSON)
{ "code": "a3f9d2e1b4c87f2d9e6a3b8c1d4e7f2a...", "weight_kg": 4.5 }
Response
200 OK
{ "message": "Pickup confirmed!", "weight_kg": 4.5, "points_credited": 45, "pickup_status": "completed" }
GET
My Pickup Requests
/api/pickup/my-pickups/
Returns all pickup requests made by the logged-in user with their current status and points credited.
🔒 Token Required›
🔒 Header: Authorization: Token YOUR_TOKEN_HERE
Response
200 OK
[ { "id": 1, "waste_type": "plastic", "weight_kg": 4.5, "points_credited": 45, "status": "completed", "created_at": "2026-05-13T10:00:00Z" } ]
