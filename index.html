🔐 Authentication

These endpoints handle how users create accounts and log in. No token is needed here these are the starting points for every user journey on Ecosort.

POST
Register a New User
/api/auth/register/
The user provides their name, phone number, location and what type of user they are household, collector, buyer or brand. Once done, their account is created and onboarding begins automatically.
Public ›
Request Body (JSON)
{ "email": "amina@ecosort.com", "phone_number": "08011111111", "password": "1234", "user_type": "household", "full_name": "Amina Yusuf", "location": "Bariga, Lagos", "language": "pidgin", "waste_type": "plastic" }
Response
201 Created
{ "message": "Registration successful!", "userId": 1, "userType": "household" }
POST
Login with Phone Number
/api/auth/login/
This is the gate into Ecosort. A user enters their phone number and password. If correct, they receive a token like a key that lets them access their profile, onboarding and other protected parts of the platform.
Public ›
Request Body (JSON)
{ "phone_number": "08011111111", "password": "1234" }
Response
200 OK
{ "message": "Login successful!", "token": "9944b09199c62bcf9418ad846dd0e4bbdfc6ee4b", "userId": 1, "userType": "household" }
POST
Request OTP
/api/auth/request-otp/
For users who find passwords difficult, especially elderly users or those not tech-savvy, this endpoint generates a 4-digit one-time code tied to their phone number. Think of it like the code your bank sends you via SMS. In production, this code will be delivered via SMS through Termii. It expires after 10 minutes.
Public ›
Request Body (JSON)
{ "phone_number": "08011111111" }
Response
200 OK
{ "message": "OTP generated successfully!", "otp": "4521", "note": "In production this OTP will be sent via SMS" }
POST
Verify OTP
/api/auth/verify-otp/
After receiving their 4-digit OTP code, the user enters it here to confirm their identity. If the code is correct and hasn't expired, they are logged in and receive their access token,no password needed at all.
Public ›
Request Body (JSON)
{ "phone_number": "08011111111", "otp": "4521" }
Response
200 OK
{ "message": "OTP verified! Login successful!", "token": "9944b09199c62bcf9418ad846dd0e4bbdfc6ee4b", "userId": 1, "userType": "household" }
👤 User Profile

These endpoints let users view and update their personal information stored on Ecosort. A valid token from login is required,the system needs to know whose profile to show or update.

GET
Get My Profile
/api/profile/me/
Fetches all the profile details of the currently logged-in user,their name, location, preferred language, what channel they use (WhatsApp, USSD or App) and their waste type. Like opening your profile page on any app.
🔒 Token Required ›
🔒 Add this to your request headers: Authorization: Token YOUR_TOKEN_HERE
Response
200 OK
{ "fullName": "Amina Yusuf", "location": "Bariga, Lagos", "languagePreference": "pidgin", "channel": "whatsapp", "wasteType": "plastic" }
PUT
Update My Profile
/api/profile/me/
Allows the logged-in user to update their profile details, change their location, switch their preferred language, update their waste type or channel. Like editing your profile settings on WhatsApp or Instagram.
🔒 Token Required ›
🔒 Add this to your request headers: Authorization: Token YOUR_TOKEN_HERE
Request Body (JSON)
{ "fullName": "Amina Yusuf", "location": "Surulere, Lagos", "languagePreference": "english", "channel": "whatsapp", "wasteType": "organic" }
Response
200 OK
{ "message": "Profile updated!" }
🎯 Onboarding

Every new user goes through a 5-step onboarding journey before using Ecosort fully. These endpoints track their progress and reward them when they complete all 5 steps.

GET
Check Onboarding Progress
/api/onboarding/status/
Shows exactly where a user is in their onboarding journey which of the 5 steps they've completed and which ones are still pending. Think of it like checking your progress bar when setting up a new phone.
🔒 Token Required ›
🔒 Add this to your request headers: Authorization: Token YOUR_TOKEN_HERE
Response
200 OK
{ "currentStep": 3, "step1Completed": true, "step2Completed": true, "step3Completed": false, "step4Completed": false, "step5Completed": false, "isCompleted": false, "startedAt": "2026-04-25T10:00:00Z", "completedAt": null }
POST
Complete an Onboarding Step
/api/onboarding/complete/
Called each time a user finishes one of the 5 onboarding steps. When they complete step 5 — the final step — the system marks their onboarding as done and automatically queues their first reward notification. This reward is Ecosort's way of saying "Welcome, you're ready to sort waste and earn!"
🔒 Token Required ›
🔒 Add this to your request headers: Authorization: Token YOUR_TOKEN_HERE
Request Body (JSON)
{ "step": 1 }
Response (Steps 1–4)
200 OK
{ "message": "Step 1 completed!", "nextStep": 2 }
Response (Step 5 — Final)
200 OK
{ "message": "Onboarding complete! First reward notification queued." }
