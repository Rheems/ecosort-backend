Authentication
POST /api/auth/register/ Create new account ▾
Request Body
Field Type Required
email string required
phone_number string required
password string required
user_type household | collector | buyer | brand required
full_name string required
location string optional
language english | pidgin optional
waste_type plastic | paper | glass | metal | organic | mixed optional
Response (201)
{ "message": "Registration successful!", "userId": 1, "userType": "household" }
POST /api/auth/login/ Login with phone & password ▾
Request Body
Field Type Required
phone_number string required
password string required
Response (200)
{ "message": "Login successful!", "token": "abc123...", "userId": 1, "userType": "household" }
POST /api/auth/request-otp/ Request OTP code ▾
Request Body
Field Type Required
phone_number string required
Response (200)
{ "message": "OTP generated successfully!", "otp": "1234" }
POST /api/auth/verify-otp/ Verify OTP & get token ▾
Request Body
Field Type Required
phone_number string required
otp string required
Response (200)
{ "message": "OTP verified! Login successful!", "token": "abc123...", "userId": 1 }
